## 一、、疾病流行病学核心数据
1. **国内糖尿病现状**
    我国糖尿病人超**1.4亿**，全球第一；2018年成人糖尿病患病率12.4%，糖尿病前期38.1%。
2. **DR患病情况**
    - 全球：糖尿病患者DR总患病率34.6%，PDR 6.96%，DME 6.81%；2020年全球DR患者1.031亿，2045年预计1.605亿。
    - 中国：糖尿病合并DR患病率**22.4%**；农村（34.0%）＞城市（18.7%），华北、东北高发；50～59岁人群患病率最高。
    - 发病概率：每3名糖尿病患者约1人发生DR，是**劳动年龄人群首位致盲眼病**。
3. **核心危险因素（可干预优先）**
    ① 糖尿病病程（最强危险因素）；② 高糖化血红蛋白、血糖控制差；③ 高血压、高血脂；④ 吸烟、肥胖、肾病、妊娠、遗传。

## 二、DR与DME标准分型（国内通用）
### （一）糖尿病视网膜病变DR六期（2014版沿用）
1. **非增生型NPDR**
    - Ⅰ期（轻度）：仅微血管瘤
    - Ⅱ期（中度）：出血、硬性渗出、棉绒斑
    - Ⅲ期（重度）满足任意1条：每象限≥20个出血点；2象限静脉串珠；1象限IRMA；≥2条为**极重度NPDR**
2. **增生型PDR**
    - Ⅳ期（增生早期）：视盘/视网膜新生血管（NVD/NVE），伴积血为**高危PDR**
    - Ⅴ期（纤维增生）：纤维血管膜，可伴出血
    - Ⅵ期（增生晚期）：牵拉性视网膜脱离
### （二）糖尿病黄斑水肿DME二分法（2017国际更新，指南主推）
1. **NCI-DME（未累及中心凹）**：黄斑增厚未波及中心凹1mm范围
2. **CI-DME（累及中心凹）**：水肿侵犯黄斑中心凹，**损害中心视力，抗VEGF一线治疗**
补充旧分类：临床有意义黄斑水肿CSME，为传统激光治疗指征。

## 三、标准化筛查方案（启动时间+随访频率）
### 1. 首次筛查启动节点
- **1型糖尿病**：12岁前发病→12岁起每年查；12岁后发病→患病5年内启动筛查
- **2型糖尿病**：**确诊当天立即筛查眼底**
- **糖尿病合并妊娠**：首次产检筛查，孕期每3个月复查，产后1年复查
- 妊娠期糖尿病：指南无统一眼底筛查推荐

### 2. 分层随访周期
| 眼底分级 | 复查间隔 |
| ---- | ---- |
| 无DR | 1～2年 |
| 轻度NPDR | 6～12个月 |
| 中度NPDR | 3～6个月 |
| 重度NPDR | ＜3个月 |
| PDR | 每月随访 |
| NCI-DME | 3个月 |
| CI-DME | 每月 |

### 3. 转诊指征
视力≤0.7、突发视力下降/视物模糊，立即转诊眼底专科。

## 四、诊断与影像学检查（优缺点、推荐意见）
### 1. 眼底照相
- 金标准：ETDRS 7视野立体眼底照相，用于分期与科研分级
- 超广角眼底照相（200°）：免散瞳、成像快、可多检出20%～30%周边病灶；与7视野一致性中-高，**推荐用于基层筛查**（专家意见）；缺陷：睫毛遮挡易漏诊局部病变。

### 2. OCT（DME核心检查）
核心用于定量黄斑厚度（CRT），识别4类关键预后生物标志物：
1. **囊状视网膜内积液IRC**：内核层积液对抗VEGF应答更好
2. **视网膜下积液SRF**：提示视力差，但抗VEGF治疗解剖获益更佳
3. **强反射点HRF**：数量多提示药物应答差、炎症活跃
4. **视网膜内层结构紊乱DRIL**：提示黄斑缺血，持续存在预示视力预后不良

### 3. FFA荧光素眼底血管造影
- 优势：清晰显示无灌注区、渗漏、新生血管动态渗漏，指导激光方案
- 缺陷：有创、造影剂过敏风险，肝肾不全、妊娠慎用

### 4. OCTA（无创血管成像）
- 优势：无需造影剂，分层显示视网膜血管，识别IRMA、NVE、无灌注区，适合长期随访
- 不足：无法观察血管动态渗漏；微小微动脉瘤检出灵敏度低于FFA
- 推荐：配备设备机构可联合OCT用于DR/DME随访（弱推荐，低质量证据）

## 五、DR全阶段治疗方案
### （一）基础全身管理（强推荐，中等证据）
**推荐意见1**：1/2型糖尿病患者需科学平稳控糖，兼顾低血糖与心血管风险；同时严格控制血压、血脂，内分泌协同眼科共管。
- 不盲目强化降糖：老年、心血管基础病患者放宽糖化目标；长期控糖可延缓DR发生、阻止向增生期进展。

### （二）增生前/增生期DR眼部治疗
#### 1. 全视网膜激光光凝PRP（国内一线金标准）
适用：极重度NPDR、高危PDR；可降低50%以上严重视力丧失、玻璃体切割风险。
标准参数：光斑200～500μm，曝光0.1～0.3s，光斑总数1200～1600，避开黄斑与视盘。
优势：费用低、3～4次完成，适合依从性差、经济受限患者；缺点：周边视野不可逆缺损。

#### 2. 抗VEGF单药/联合PRP（弱推荐，低证据）
适用：重度NPDR、非高危PDR伴视力下降，无玻璃体积血/牵拉脱离
- 单用抗VEGF：2年视力获益不劣于PRP，视野损伤更少；缺点：需长期频繁注射、依从性要求高、费用高，**无法逆转视网膜无灌注区进展**。
- 联合PRP：减少激光用量、降低玻璃体积血、减少注射次数，视力获益优于单一方案。
国内可用药物：雷珠单抗、阿柏西普、康柏西普（国产融合蛋白，半衰期更长）。

#### 3. 玻璃体切割PPV手术
**手术指征**：长期不吸收玻璃体积血、牵拉性视网膜脱离、纤维血管膜、合并虹膜新生血管。
**推荐意见5**：手术前/术中联合抗VEGF注射，减少术中出血、缩短手术时间、降低术后再积血风险（弱推荐，低证据）。

## 六、DME糖尿病黄斑水肿分层治疗（指南核心重点）
### 1. CI-DME（累及中心凹，视力下降）：抗VEGF为一线
#### （1）三类国内获批药物对比
1. **雷珠单抗**：单抗，3+PRN经典方案；基线视力差患者改善显著
2. **阿柏西普**：融合蛋白，5针负荷后每8周维持，注射频次更少；基线视力严重受损人群获益最优
3. **康柏西普**：国产多靶点融合蛋白，半衰期长，3～5针负荷后PRN，2年平均注射仅10次左右

#### （2）主流给药方案
- 负荷强化（指南强调必需）：连续3～5个月每月注射，快速消退水肿、保护视力
- 维持方案（无统一强推荐，个体化选择）
  ① PRN按需注射：病情活动再给药，注射总量最少，需高频随访
  ② T&E延长给药：每次就诊注射，稳定后拉长间隔，随访次数更少
  ③ 固定周期给药（Q4W/Q8W）：疗效稳定，但注射负担重

#### （3）难治性DME（抗VEGF应答差）
定义：24周≥4次注射，CRT持续＞250μm；约40%患者出现持续性水肿。
**推荐意见9**：可更换眼内缓释激素（地塞米松植入剂Ozurdex）二线治疗；人工晶体眼、心脑血管高危人群可直接激素一线。
- 激素优势：注射间隔长达4～6个月，减少就诊；副作用：眼压升高、加速白内障进展。

### 2. 激光治疗（分场景使用）
1. **NCI-DME（未累及中心凹）**：改良ETDRS局灶/格栅激光为首选，无需长期眼内注射
2. **阈值下微脉冲激光**：CRT＜400μm轻度水肿适用；联合抗VEGF可减少注射次数（弱推荐）
3. 传统格栅激光：仅用于经济条件差无法承担药物的CI-DME，疗效弱于抗VEGF

### 3. 手术治疗DME
仅用于玻璃体黄斑牵拉导致的持续性水肿：PPV联合内界膜剥除，不作为首选，存在视力下降风险。

### 4. 合并白内障的DME处理（推荐意见11）
白内障术前优先控制黄斑水肿；无法窥清眼底可先行白内障手术；**术中同步玻璃体腔注射抗VEGF/激素**，术后视力提升更显著。
